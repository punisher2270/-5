# -5
Анализ кейса № 2 
Аналитический обзор
В ходе выполнения работы была разработана тестовая программа, демонстрирующая взаимодействие базового и производного классов, а также вызов их методов. Программа выполняет поставленную задачу корректно: объект производного класса успешно обращается как к собственному методу, так и к методу базового класса, что подтверждает правильную реализацию наследования и доступ к унаследованным элементам.

Функциональность
С точки зрения функциональности программа реализует все требуемые возможности. Она создаёт объект производного класса, вызывает метод базового класса и метод производного класса, а также выводит на экран соответствующие сообщения, позволяя наглядно убедиться в работоспособности иерархии классов.

Программа не содержит сложной логики ввода и обработки данных, поэтому риск ошибок минимален, а результат работы является предсказуемым и однозначным. Это делает её удобной для демонстрации принципов наследования и проверки правильности структуры классов.

Производительность
С точки зрения производительности программа работает быстро, поскольку выполняет только несколько простых операций: создание объекта и последовательный вызов методов. Такие действия не требуют значительных вычислительных ресурсов и практически не зависят от объёма данных.

Для подобного учебного примера скорость выполнения можно считать высокой, а задержки — отсутствующими. Следовательно, программа соответствует требованиям по производительности для демонстрационных задач и может использоваться без дополнительной оптимизации.

Итоговая оценка
В целом проделанная работа выполнена успешно. Программа полностью демонстрирует работу методов базового и производного классов, корректно реализует наследование и отличается высокой скоростью выполнения в рамках своей задачи.
